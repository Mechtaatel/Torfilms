# Домашний HTTPS на Android

Сайт: https://192.168.0.122:18184/

1. Подключите телефон к домашнему Wi-Fi.
2. Скачайте публичный сертификат:
   http://192.168.0.122:18182/p2p/torfilms-home-ca.crt
   Если порт недоступен, перенесите `public/p2p/torfilms-home-ca.crt` по USB.
3. В настройках Android найдите «Установить сертификат» → «Сертификат CA».
   Раздел может называться «Безопасность» → «Шифрование и учётные данные».
   Выберите скачанный файл и подтвердите установку **Torfilms Home CA 2026**.
4. Откройте сайт по HTTPS. Не используйте HTTP на порту 18184.
   Если браузер всё ещё предупреждает о сертификате, не обходите предупреждение.

SHA-256 сертификата (сверьте при передаче по HTTP):
`CD:60:B0:29:7B:45:BE:F4:39:3E:3A:F5:63:94:30:30:7F:07:91:54:1F:67:D6:F7:2F:5C:08:C3:4E:20:56:5E`

Это локальный корневой центр доверия: его установка меняет доверие устройства.
После домашнего теста удалите **Torfilms Home CA 2026** из пользовательских
доверенных сертификатов Android (не удаляйте все сертификаты).
Никому не передавайте файлы `.local-tls/*key.pem`; они не нужны телефону.
На компьютере корневой сертификат автоматически не устанавливался.

Корневой сертификат действителен 365 дней, серверный — 180 дней с выпуска.
При изменении IP компьютера потребуется новый серверный сертификат с новым SAN.
Закрепите текущий IP в DHCP-настройках роутера при необходимости.

Запуск: сначала `npm run bridge`, затем `powershell -File .\start-bridge-lan.ps1`.
Скрипт автоматически использует существующие сертификаты из `.local-tls`.
Не публикуйте домашний мост в интернете и не включайте проброс порта на роутере.
